# v40 / r21 (31 Oct 2026)

## What changed

- 256 KB guest image: boot loads 528 sectors (16 kernel + 512 guest), kernel
  copies 256 KB. Guest slot is now 32,768 words.
- Real VGA framebuffer: mode 13h 320x200x8, linear A0000. Kernel ops:
  FBINFO, VSYNC, FBCOPY, FBFILL, OUTB, INB; VPOKE/VPEEK are mode-aware.
- VGA mode-set register sequence is NaN16 code in src/lib/fb.nas. The native
  kernel only exposes port I/O and framebuffer mapping.
- Homebrew 3x5 font, 64 glyphs, 2x scale, 1px gaps. fb_char3 / fb_text3.
- Sierpinski cartridge: 320x128 pixel rule-90 lattice, white on black, live
  scroll; lower 72px is a scrollable 3x5-font label. Exact dev note included.
- Boole cartridge: 98-line scrollable plaque, live 16 functions, mirror law,
  word lab. V_SCROLL is a general shell vector.
- About NaN/0S and About Shemshallah cartridges, scrollable.
- Trust exhibit: preface + full paper (376 lines), scrollable. Paper:
  spec/TRUST_PAPER.md.
- Curator Console: `~` opens a read-only raw guest word view.
- Seven TOC entries. Image is 13,767 guest words. Patriot Missile Failure
  (1991) added as a scrollable, fact-checked plaque.
- Sparse allocation prototype: tools/mkalloc.py creates a 64 GiB apparent
  NANFS image with ~1.5 MiB allocated.
